# Implementation Plan: Links Frontend IA - Phase 2 Site Architecture

**Branch**: `002-links-frontend-ia-phase-2` | **Date**: `2026-05-09` | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from [`spec.md`](spec.md)

**Note**: This plan describes the implementation strategy for Phase 2 site architecture and data integration.

## Summary

Implement the site architecture for Links Frontend IA 2026: create dynamic category pages, organize links by subcategories, implement responsive card/list layouts (desktop/mobile), add search functionality with 3-character minimum, and integrate existing JSON data from `preproyecto/jsons-news-interficies/`.

## Technical Context

**Language/Version**: TypeScript 5.x + Astro 6.1.9 + React 19  
**Primary Dependencies**: Astro (routing, SSR), React (components), Tailwind CSS 4, shadcn/ui, Lucide icons  
**Storage**: JSON files from `preproyecto/jsons-news-interficies/{category}/` loaded at build/render time  
**Testing**: Local `bun run dev`, responsive testing (mobile-first), search validation  
**Target Platform**: Browser-based static/SSR web application  
**Project Type**: Web application with dynamic routes and client-side search  
**Performance Goals**: Pages load <2s; search filters in real-time; smooth layout transitions  
**Constraints**: Path-length safe for GitHub; mobile-first responsive; non-AI design compliance; no i18n in this phase  
**Scale/Scope**: 14 category pages, dynamic subcategory sections, ~500-2000 total links across all categories

## Key Decisions

1. **One dynamic page vs. static generation**: Using Astro `[...slug].astro` for flexibility; can optimize with static pre-generation later.
2. **Data location**: Keep JSON in `preproyecto/`; import into components at build time (no duplication).
3. **Component library**: shadcn/ui for base components + custom Tailwind for category-specific styling.
4. **Search**: Client-side JavaScript; filters by name/description in real-time.
5. **Responsive breakpoints**: Tailwind defaults (`sm`, `md`, `lg`); mobile-first cascade.
6. **Bilingual**: Labels in Spanish in Phase 2; defer i18n to Phase 3+.
